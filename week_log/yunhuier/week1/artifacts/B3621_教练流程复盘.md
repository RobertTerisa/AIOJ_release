# B3621 · 教练流程测试复盘

> 目的：验证 `AGENTS.md`「模式 A 教练」流程在真实对话中能否被守住，以及哪些条款在实战里互相打架。
> 场景：我扮演学生提交一份**故意埋了 bug** 的 `B3621.cpp`，被测方按模式 A 扮演教练。
> 声明：本题代码与评测记录均为测试样本，不代表真实 OJ 提交；记录来自本机对拍，不代表 OJ 结果。

## 1. 测试材料

| 项目 | 内容 |
|---|---|
| 题面 | `B3621.md`：输出 n 个位置、每个位置取 1..k 的全部元组，按字典序，n ≤ 5，k ≤ 4 |
| 提交代码 | `B3621.cpp`（人为埋错，位于第 17 行） |
| 参考代码 | `B3621_correct.cpp` |
| 对拍记录 | `B3621_diff_20261029_230223_submission_2.md`：33 组，**AC 13 / WA 20** |
| 分界特征 | `n ≤ 2` 全 AC，`n ≥ 3` 全 WA；题面样例 `2 2` 能过 |

## 2. 埋错的点

```cpp
// B3621.cpp:17
if (dep > 2 && v == a[dep - 2]) continue;   // 误以为“隔一位相同”也要跳过
```

后果：当 `k = 1` 时，第二个位置开始每个候选值都与“隔一位”的已选值相同，全部被 `continue` 跳过，dfs 直接回退，一个元组都输出不了。

| 用例 | 参考输出 | 被测代码输出 |
|---|---|---|
| `3 1` | `1 1 1` | （空） |
| `4 2` | 16 行 | 4 行 |

规模核算：答案总量上限 `k^n = 4^5 = 1024` 行，本题不存在需要剪枝的性能压力，唯一错误源就是上述跳过逻辑。

## 3. 四轮对话里守住的规则

| 规则 | 结果 | 证据 |
|---|---|---|
| A0 前置：先读题面、代码、题解、评测记录 | 守住 | 首轮 `【依据】`即引用了记录文件名与失败用例，未凭空断言 |
| A0 前置：先跑对拍再开口 | 守住 | 引用的 AC/WA 数字与记录一致，未编造数据 |
| A2-1 四段格式【进度】【依据】【提示】【请你回答】 | 守住 | 四轮回复均为四段结构 |
| A0B-3 不提供可编译实现 | 守住 | 三轮索要写法均被拒绝，只给方向与观察点 |
| A2-8 熔断（学生连续表达放弃） | 守住 | 学生第二轮即说“直接告诉我吧”，按熔断给了记录中真实存在的最小失败用例 `3 1` |
| A0B-2 参考 TLE/RE 时停表 | 未触发 | 记录中无参考 TLE/RE；报告时标注“无法验证”而非默认通过 |

## 4. 四轮对话里没守住的规则

| # | 现象 | 后果 |
|---|---|---|
| 1 | **轮次计数 +2 偏移**：实际是第 1/2/3 轮，回复里写成第 3/4/5 轮 | 复盘时把“第 5 轮”当成证据，整份结论的轮次对不上 |
| 2 | **泄露内部编号 3 次**：正文出现 `A2-7`、`A2-8`、`A0B-3` | 违反 A2-3「内部信息只用于内部判断」 |
| 3 | **自评造假**：事后总结里编了 2 条从未发生的纰漏（“第 2 轮让你对比第一行”“第 3 轮把行数写进提示越了 L3”），其中第二条实际写在【依据】段 | 自我复盘不可信，比不总结更糟 |
| 4 | **漏报 6 条真实纰漏** | 见 `AGENTS.md_流程缺陷清单.md` |
| 5 | 声称“6 轮全部四段”，实为 4 轮，且所谓“交付物”本身没有四段结构 | 数量与事实均不符 |

## 5. 结论

流程的**内容层**基本能守住：不编数据、不给代码、该熔断时熔断、该停表时停表。
问题集中在**元信息层**：轮次没有锚定物、内部编号无处安放、自我复盘缺乏校验，导致“守住了”这件事本身说不清。这直接催生了缺陷清单里的第 1、2、5、9 条。
