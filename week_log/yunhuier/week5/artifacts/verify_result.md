# 第 5 周验收记录 · 两段式（双峰）序列生成器

> 验收脚本：`artifacts/test_week5.py`（23 项，全部 PASS）
> 环境：Windows 11 / g++ 8.1.0（`-O2 -std=c++17 -Wall -Wextra`，编译零警告）
> 声明：以下为本机实测，不代表 OJ / CI 环境。

## 1. 调用方式

```bash
seq_bimodal.exe --seed 123 --out case_001.in --append --array 1000000,1,1000001
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `--seed` | 是 | 同一 seed 逐字节一致 |
| `--out` | 是 | 输出路径 |
| `--append` | 否 | 由路由传入，只追加 content |
| `--array N,i_min,i_max` | 至少一个 | 可重复；`N` 即任务单的序列长度 |

## 2. 构造算法

设 `span = i_max - i_min`，`band = span*3/10`（整数除法）：

1. 区间1 = `[i_max - band, i_max]`，区间2 = `[i_min, i_min + band]`；
2. 掷布尔：`0 → 区间1`，`1 → 区间2`（等概率）；
3. 在选中区间内均匀取数；
4. 当 `band < 1`（即 `span ≤ 3`）时**静默**退化为在 `[i_min, i_max]` 上均匀取，不报错。

## 3. 样例输出

`--seed 42 --array 20,1,101`（span = 100，band = 30，中间 `(31, 70)` 应为空档）：

```
20 5 3 12 83 87 20 30 14 73 5 74 73 14 4 11 25 99 13 71
```

可以看到取值只落在 `[1, 31]` 与 `[71, 101]` 两段，`31 < x < 71` 一个都没有。

`--seed 7 --array 200000,1,1000001`（每段宽 300000）：
