# 第 2 周生成器验收记录

- 环境：Windows 11，g++ 8.1.0，编译参数 `-O2 -std=c++17`，Python 3.13.9
- 方法：每个生成器连续运行 3 次（取其最慢值），每次运行后校验输出的文件内容
- 校验项：`T == 1`、`n` 是否符合任务单规模、元素个数是否等于 n、元素下界是否 ≥ 1、上界是否 ≤ 变体规定的 max、全相等变体是否真的全相等、耗时是否 < 1 s

> 本记录为本机实测结果，不代表 OJ 评测环境。

## 1. 汇总

| 生成器 | 最慢耗时(ms) | 三次耗时(ms) | 输出字节 | 元素个数 | min | max | 全相等 | 判定 |
|---|---|---|---|---|---|---|---|---|
| gen_template | 235.5 | 235.5 / 10.8 / 10.5 | 78 | 10 | 134017 | 948547 | 否 | PASS |
| gen_random_small | 110.5 | 110.5 / 12.6 / 10.6 | 34429 | 5000 | 120 | 999573 | 否 | PASS |
| gen_random_large | 256.8 | 256.8 / 164.3 / 158.9 | 6889114 | 1000000 | 1 | 1000000 | 否 | PASS |
| gen_all_equal | 350.1 | 350.1 / 200.7 / 112.1 | 8000013 | 1000000 | 3615694 | 3615694 | 是 | PASS |

首次运行包含进程冷启动与磁盘缓存未命中的开销，因此耗时高于后两次；后两次即稳定值。

## 2. 逐项校验明细

| 生成器 | T==1 | n 正确 | 元素个数==n | min≥1 | max≤变体上界 | 全相等 | <1 s |
|---|---|---|---|---|---|---|---|
| gen_template | ✓ | ✓（10） | ✓ | ✓ | ✓（≤1000000） | — | ✓ |
| gen_random_small | ✓ | ✓（5000） | ✓ | ✓ | ✓（≤1000000） | — | ✓ |
| gen_random_large | ✓ | ✓（1000000） | ✓ | ✓ | ✓（≤1000000） | — | ✓ |
| gen_all_equal | ✓ | ✓（1000000） | ✓ | ✓ | ✓（≤10000000） | ✓ | ✓ |

## 3. 输出文件格式

三个随机变体的首两行固定为：

```
1
<元素个数>
<以空格分隔的元素，行末换行>
```

与 `UVA10364.in` 所需的“组数 T / 每组 n / 每组 n 个数”结构一致；`1` 表示单组数据。

## 4. 备注

- 任务单中 min/max 写作 `(i_min, i_max)`，未明确开闭区间；本次按**闭区间**实现，元素可取到端点值（`gen_random_large` 的实测最大值恰好取到 1000000）。
- 全相等变体的上界按任务单原文取 10000000，与另两档的 1000000 不同，属任务单既有设定，未擅自统一。
